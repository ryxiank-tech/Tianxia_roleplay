# EVENTS

Event dibagi menjadi:
- Local: memengaruhi desa/kota.
- Regional: memengaruhi beberapa wilayah.
- Major: mengubah keseimbangan faksi atau jalur sejarah.

Event berjalan berdasarkan waktu, bukan hanya ketika pemain hadir. Bila pemain mengabaikan masalah, dunia boleh bergerak tanpa mereka.

Contoh event awal: Festival Perahu Sungai Qingshui, sengketa pajak jembatan, hilangnya tiga pedagang, dan kemunculan jejak makhluk di Hutan Wuyan. Detail kejadian harus ditentukan ketika event dimainkan.
