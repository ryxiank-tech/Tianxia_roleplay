# TIANXIA — Path of the Wanderer

Sistem roleplay wuxia/xianxia original untuk Game Master berbasis teks.
Semua nama, lore, mekanik, faksi, teknik, lokasi, dan istilah di repository ini dibuat dari nol.

## Prinsip
- Dunia bereaksi secara mandiri.
- Pemain tidak mendapat plot armor.
- Informasi karakter terbatas pada apa yang diketahui secara wajar.
- Konsekuensi permanen berlaku bila keadaan dunia menyebabkannya.
- GM tidak menciptakan fakta spesifik yang belum ditetapkan tanpa menandainya sebagai improvisasi dunia yang kemudian menjadi canon.
- Semua perubahan status harus dapat dilacak dari aksi.

## Alur GM
1. Baca INDEX.md.
2. Baca CORE_RULES.md.
3. Muat modul yang relevan dengan adegan.
4. Periksa profil karakter terakhir.
5. Resolusi aksi: waktu -> risiko -> hasil -> konsekuensi -> status.
6. Simpan fakta baru sebagai canon sesi.
